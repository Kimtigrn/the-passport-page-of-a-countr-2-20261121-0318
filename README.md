An open passport spread for the Republic of Valdris, a country that isn't there: a data page with a portrait and a machine-readable zone with correct ICAO check digits, entry and exit stamps from the neighbouring states of Ostara, Dravnik and Kalmere, a Kalmere visa, and the conditions of issue — including that the passport is not valid for travel to the Northern Fisheries without a permit. Drawn entirely in stdlib Python: a hand-built 5x7 bitmap font, vector portrait, stamps and seals, rendered at 2x and downsampled to a 1024x720 PNG.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x720 PNG, deterministic — two runs are byte-identical).
